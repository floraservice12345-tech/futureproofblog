# BharatBiz Content Studio

Independent static web app for Indian small-business content planning.

The prompt builder prepares a structured prompt locally; it does not call ChatGPT, Claude, or any API. The paid offer is a 30-day content calendar for ₹3,500 through a Netlify enquiry form. This is a lead request, not a checkout, and no sales outcome is promised.

## Deploy

Connect the existing GitHub repository to a separate Netlify site, choose the ai-content-studio branch, and publish the repository root. No build command is required. Enable Netlify Forms. After Netlify assigns the public URL, update the canonical URL in index.html.

## Privacy and cost

No model/API subscription is required. Prompt inputs stay in the browser. Form data goes to Netlify only when a visitor submits the enquiry.
